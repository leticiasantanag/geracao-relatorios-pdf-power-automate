# Geração automática de relatórios em PDF

Desenvolvi esta automação com Power Apps e Power Automate para transformar informações já registradas em um relatório PDF organizado por diretoria.

A proposta é facilitar a preparação do documento, reunindo a busca dos dados, a organização do conteúdo e a geração do arquivo em um único processo.

## Como funciona

A pessoa inicia a geração do relatório pelo Power Apps. A partir desse comando, o Power Automate executa as etapas:

1. Consulta os registros utilizados no relatório.
2. Agrupa as informações por diretoria.
3. Monta o conteúdo do documento em HTML.
4. Converte o documento para PDF.
5. Salva o arquivo e retorna um link para acesso pelo aplicativo.

## Minha participação

Desenvolvi o fluxo de automação, a organização das informações e a montagem do conteúdo do relatório, incluindo a conversão para PDF e o retorno do link ao Power Apps.

Um dos pontos importantes do projeto foi organizar os registros por diretoria, para que o documento apresentasse as informações separadas e em uma sequência clara.

## Tecnologias utilizadas

- **Power Apps:** ponto de partida para solicitar o relatório e receber o link.
- **Power Automate:** execução das etapas da automação.
- **HTML:** estrutura e formatação do conteúdo antes da conversão.
- **OneDrive for Business:** conversão do documento em PDF.

## Aplicação prática

A automação permite gerar um documento a partir dos dados disponíveis, sem montar cada relatório manualmente.

Este repositório apresenta o funcionamento do projeto como parte do meu portfólio profissional. Dados internos e configurações do ambiente de trabalho não são disponibilizados.
